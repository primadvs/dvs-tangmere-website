Phase 1 · Week 1

Acquire the .aero domain

Days 1–2

Apply for Aero ID membership

External dependency

.aero is a restricted domain, reserved for the civil aviation community. Registration requires an Aero ID membership from the registry (SITA) before any registrar will sell the name.

  • Tangmere qualifies squarely — the eligible categories include Business Aircraft Operator, Distribution and Aviation Professional.
  • Have ready: company registration, and evidence of aviation activity (this website is itself good evidence).

Published turnaround from the registry is around two working days once eligibility is confirmed.

Days 3–5

Register the domain

Done
  • tangmere.aero is registered through Netim.com, an accredited .aero registrar. At checkout it was $68.49 for the first year, renewing at $89.99 a year.
  • Not needed, so not bought: a separate email hosting plan (Google Workspace is the email host), an SSL certificate and the registrar's CDN add on (the site host provides both). WHOIS privacy is optional; confirm what was chosen.
  • The current tangmere-aircraft.com stays live and untouched the entire time — this runs in parallel, with no risk to the working site.
  • Chris Edwards' email is the account holder for this purchase and all related acquisitions (the domain, and anything else bought during this rollout).
Right after registering

Move the domain's DNS to Cloudflare

Done

Cloudflare Pages can only attach a bare domain like tangmere.aero if the domain's DNS is on Cloudflare, so the nameservers set at Netim change to the two Cloudflare supplies. Until this step they stay on Netim's defaults and nothing on that screen is touched.

  • Create a free Cloudflare account under Chris Edwards' email and add tangmere.aero. Cloudflare copies the existing DNS records and shows them for checking.
  • Only then, in Netim, choose custom nameservers and enter the two Cloudflare gives.
  • This is the safest moment to do it, before email or the site are live, because nothing can break. It can take up to 48 hours to settle.
  • From here on, every DNS record (the Google Workspace mail records, the site) is entered in Cloudflare, not Netim.

Done: Cloudflare is active for tangmere.aero and the public lookup shows its nameservers. Netim's old mail records were removed. The two A records pointing at Netim's parking page remain until the website is connected.

Phase 3 · Weeks 2–3

Plan the migration

Decide first

How the two domains relate

Decided

Move to tangmere.aero. Both domains run alongside each other during the migration itself, specifically to limit friction and downtime while the switch happens — not as a permanent arrangement. Once the transition is complete, tangmere.aero is the one home for the site and tangmere-aircraft.com redirects fully to it. Nothing already in circulation breaks at any point, and the new domain ends up carrying the aviation specific credibility of a .aero address as Tangmere's single address, not a parallel one.

Then

Redirects

  • 301 redirects from every current tangmere-aircraft.com page to its new domain equivalent, so no link anyone has already shared or bookmarked breaks.
  • A written rollback plan: DNS reverted to the current site within minutes if the new one shows a problem after go live.
Hosting

Cloudflare Pages

Connected

The site moves off GitHub Pages, which has no way to run a form and whose terms say it isn't meant for running an online business. Cloudflare's free plan has unlimited bandwidth, 500 builds a month and needs no card. It builds the site straight from the GitHub repository, so GitHub stays the master copy.

Done: connected to the GitHub repository and deployed, checked and rendering correctly at dvs-tangmere-website.pages.dev. This is a free preview address only — tangmere.aero does not point at it yet, so nothing has changed for real site visitors. Every future push to GitHub rebuilds this preview automatically.

  • The terms don't ban business use. A free site can't collect card details, and Tangmere's site takes none.
  • Free services carry no liability and Cloudflare may suspend an account at any time, so the site can be redeployed to another host within minutes if that ever happens.
  • A single file can be at most 25 MiB. The current 32.9 MB hero video is over that and would not deploy, so the replacement has a size target: 1080p, 10 to 15 seconds, no audio, roughly 3 to 6 MB, with a poster frame taken from the video itself.
  • Cloudflare's CDN terms let it limit customers who serve video or a large share of big files without paid services. A short looping clip of a few MB is unlikely to count, but it is another reason to keep the video small.

Netlify was the earlier choice. Its free plan turned out to be 300 credits a month with a hard stop: each publish costs 15 credits, bandwidth costs 20 credits per GB, and running out pauses every site on the account. Its free, ready made form handling is the one thing given up.

Weeks 2–3

Azure — how the contact form works

Code written

An Azure Function behind /api/enquiry validates the submission, checks it isn't spam, writes it to Table Storage as a permanent record, then notifies sales@ via the Gmail API, with the enquirer's own address set as Reply To. This is what turns "an email was sent" into "an enquiry exists and can be found again."

Cloudflare Pages has no form handling of its own, so this Function is now the only way enquiries reach a mailbox. The code is written and saved in the repository at backend/, with its own README, but not yet deployed or tested — there was no way to run it locally, so the first real test happens once it is live in Azure. Until then the contact form still sends nothing, which puts it on the critical path of Phase 3 rather than running alongside a quick fix.

After launch

Fleet updates by staff

The goal

Staff update the fleet without an engineer

Staff open an admin page, edit an aircraft on a form, upload photos and press Publish. The change is saved to the GitHub repository, Cloudflare rebuilds the pages, and the live site updates within minutes. Cloudflare only hosts the site; the admin page is what staff actually use.

  • Tool: Decap CMS, free and open source, with the site generated from one data file per aircraft (Eleventy suggested).
  • Login: Google sign in through DecapBridge, so each person uses the Google Workspace account they already have. No new passwords, no GitHub accounts, and removing someone who leaves is one step. DecapBridge has a free plan; its limits are not yet confirmed.
  • Photos: chosen in the aircraft form. Resizing them to web sizes is planned as part of the build so staff can upload phone photos, and any single file must stay under Cloudflare's 25 MiB limit.
  • Cost: $0 a month expected.

An engineer is needed once, to rebuild the fleet pages so each aircraft lives in a single place and to set up the admin page. Day to day use needs none. This has not been built or tested yet. The pieces are documented as working together on Cloudflare Pages, but the first real test is the build itself.

Optional: offloading media to Google Cloud Storage

Not required to launch

Today's entire media footprint is 32.9 MB — almost all of it the placeholder stock hero video. That figure is a snapshot of today's stand in content, not a stable number: once Tangmere's own footage and photography replace it, the real footprint could land smaller or larger depending on what's actually shot. That's small enough to sit inside GCS's Always Free allowance either way at this scale, but it's also small enough that git tracks it forever: every time the hero video gets swapped, the repository grows by the full file size again, not just the difference. Moving large media out of the repository and into Cloud Storage — referenced by URL rather than committed — fixes that permanently, regardless of how the footprint changes later.

GCS only earns its place here as the fix for the git bloat problem above, or if media ever outgrows that per file limit — not as a second hosting bill.

Typography

Avenir or a Hoefler & Co typeface

Real cost either way Discovery and pricing needed

The current display face (EB Garamond, paired with Inter Tight) was chosen deliberately to avoid the look of a generic AI generated site, and is free via Google Fonts. Both alternatives are paid, unlike what's live today:

  • Avenir — licensed through Adobe Fonts, roughly $20–60/month depending on tier (often already covered if anyone on the team has a Creative Cloud subscription). A geometric sans — a materially different, more modern direction than the current editorial serif look.
  • A Hoefler & Co typeface — licensed through Cloud.typography, typically from $99/year per family for web use, scaling with traffic. Which specific face (Hoefler Text, Mercury, Gotham, and others all look and cost differently) still needs choosing.

Neither option has a confirmed quote yet — before Chris picks a direction, the actual specific face needs choosing (for the Hoefler & Co route) and a real quote requested from the relevant foundry, rather than the indicative ranges above.
