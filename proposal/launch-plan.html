Phase 1 · Week 1

Acquire the .aero domain

Days 1–2

Apply for Aero ID membership

External dependency

.aero is a restricted domain, reserved for the civil aviation community. Registration requires an Aero ID membership from the registry (SITA) before any registrar will sell the name.

  • Tangmere qualifies squarely — the eligible categories include Business Aircraft Operator, Distribution and Aviation Professional.
  • Have ready: company registration, and evidence of aviation activity (this website is itself good evidence).

Published turnaround from the registry is around two working days once eligibility is confirmed.

Days 3–5

Register the domain

Registrar confirmed
  • Once the membership ID is issued, purchase through Netim.com, an accredited .aero registrar.
  • Register for a multi year term (up to 10 years) to lock in the name early rather than renew annually.
  • The current tangmere-aircraft.com stays live and untouched the entire time — this runs in parallel, with no risk to the working site.
  • Chris Edwards' email is the account holder for this purchase and all related acquisitions (the domain, and anything else bought during this rollout).

Make mail actually deliver

  • SPF, DKIM and DMARC configured on the new domain — without these, enquiry replies are likely to land in spam, which quietly defeats the whole point.
  • Wire the contact form to these mailboxes. This is the fix for today's biggest gap, and it belongs here rather than waiting — UAT in Phase 4 can't meaningfully test the form until this is done.

Phase 3 · Weeks 2–3

Plan the migration

Decide first

How the two domains relate

Decided

Run alongside. Both domains stay live: new customer contact and new enquiries route through .aero, while tangmere-aircraft.com keeps its existing traffic and links exactly as they are. Nothing already in circulation breaks, and the new domain carries the aviation specific credibility of a `.aero` address from day one.

Then

Redirects

  • 301 redirects from every current tangmere-aircraft.com page to its new domain equivalent, so no link anyone has already shared or bookmarked breaks.
  • A written rollback plan: DNS reverted to the current site within minutes if the new one shows a problem after go live.
Immediate

Netlify — the form works this week

Ships fast

Move hosting off GitHub Pages, which can't run the form at all. Netlify is a same repository swap: point the existing <form> tag at Netlify's form handling and enquiries email out, no backend to build. This alone closes today's biggest gap — nobody has to wait on Azure being built before enquiries start arriving.

Weeks 2–3, in parallel

Azure — the system underneath it

Takes longer, does more

Built alongside, not after: an Azure Function behind /api/enquiry that validates the submission, checks it isn't spam, writes it to Table Storage as a permanent record, then notifies the right mailbox via the Gmail API, using the Google Workspace mailboxes set up in Phase 2. This is what turns "an email was sent" into "an enquiry exists and can be found again."

Once both are live

Why keep both running

Not a duplicate system — two systems with different jobs, cheap enough to run together indefinitely:

  • Azure is the record of truth. Every enquiry lands in Table Storage, categorised by the dropdown, findable later.
  • Netlify is the safety net. If the Azure Function is ever down, mid deploy, or hits an unexpected error, the same form submission still reaches Netlify's handler and still emails a pilot — nothing depends on one system's uptime.
  • Total added cost of keeping both: effectively £0/month at this volume. The redundancy is close to free, which is the actual argument for running them simultaneously rather than picking one.

Optional: offloading media to Google Cloud Storage

Not required to launch

Today's entire media footprint is 32.9 MB — almost all of it the hero video. That's small enough to sit inside GCS's Always Free allowance, but it's also small enough that git tracks it forever: every time the hero video gets swapped, the repository grows by the full file size again, not just the difference. Moving large media out of the repository and into Cloud Storage — referenced by URL rather than committed — fixes that permanently.

Cost driverTypical rangeNotes
Storage$0 / mo$0.020/GB-month standard rate; 5 GB/month is Always Free in US regions — today's 33 MB fits with room for years of growth
Egress (bandwidth)~$4–40+ / mo$0.12/GB after a free allowance, and this is the real cost driver: it scales with how many visitors load the video, not with how much is stored

Worth noting: Netlify (already proposed for hosting in Phase 3) serves the same video for free as part of its own plan. GCS only earns its place here as the fix for the git bloat problem above, or if media outgrows what a hosting plan's free tier covers — not as a second hosting bill.

Copy

The "Speak to a Pilot" button

Three directions, or keep the original:

  • Enquire Now — neutral, covers buying and selling equally, not just pilots.
  • Get in Touch — warmer, less transactional.
  • Talk to Us — keeps the personal tone without the "pilot" framing.

Part of a broader pass already on the known issues list — a few phrases across the site read as generic rather than in Tangmere's own voice. That whole pass is Chris's, not just this one button.

Typography

Avenir or a Hoefler & Co typeface

Real cost either way

The current display face (EB Garamond, paired with Inter Tight) was chosen deliberately to avoid the look of a generic AI generated site, and is free via Google Fonts. Both alternatives are paid, unlike what's live today:

  • Avenir — licensed through Adobe Fonts, roughly $20–60/month depending on tier (often already covered if anyone on the team has a Creative Cloud subscription). A geometric sans — a materially different, more modern direction than the current editorial serif look.
  • A Hoefler & Co typeface — licensed through Cloud.typography, typically from $99/year per family for web use, scaling with traffic. Which specific face (Hoefler Text, Mercury, Gotham, and others all look and cost differently) still needs choosing.
File storage

Google Drive, beyond what Workspace already includes

Needs clarifying

Google Workspace Business Standard already bundles Drive with 2TB pooled storage per mailbox and shared drives — that's accounted for in the budget above. If something beyond that was meant (a dedicated shared drive structure for contracts and aircraft documentation, say), that's a real but separate ask worth spelling out once Chris has a chance to clarify it.

Language switcher

Commission translations, or remove it

The header currently offers English, French, German and Spanish, but selecting one changes nothing — no translated content exists. A control that visibly does nothing costs more trust than not having it at all, so this needs one of the two: commission real translations, or take the switcher out before Phase 4 sign off.
